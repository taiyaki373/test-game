Aegis Vanguard — Architecture & Development Roadmap

A concise overview of the runtime architecture, asset pipeline, QA flow and short development steps. Includes a Mermaid diagram and an embedded SVG for quick visual reference.

Key Components

  • index.html — single-page launcher, menu overlays, canvas setup.
  • src/game.js — game loop, entity systems, power-ups, boss logic, rendering pipeline.
  • src/procedural.js — fallback procedural sprite renderers for robust offline use.
  • src/chromakey.js — converts imgen4 green-background assets into transparent PNGs with 1px erosion to avoid green fringe.
  • src/audio.js — WebAudio synthesizer for BGM/SFX; sequencer + SFX builders.
  • tests/game.spec.js — Playwright E2E visual & collision probe; auto-screenshots saved to test-results/screenshots.
  • start.command — convenience script to start a simple HTTP server and print local IP/QR for mobile testing.

Short Development Steps (Recommended)

  1. Generate assets: node scripts/generate_imgen4_prompts.js → use imgen4 to create green-background PNGs.
  2. Process assets: place PNGs in repo root, chromakey.js will auto-convert at load time (or pre-run a headless script to batch-process and commit).
  3. Local run: chmod +x start.command; ./start.command 8000; open http://localhost:8000/
  4. Playtest balance: iterate on src/game.js values (rank, spawnRate, weapon cooldowns). Use ?testMode=true for quick cycles.
  5. QA: npm test to run Playwright; then npm run test:report to assemble gameplay GIF for review.
  6. CI: add GitHub Actions to run tests and upload screenshots/GIFs as artifacts (optional, recommended).
